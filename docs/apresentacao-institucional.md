## Apresentação do projeto

O Factory Insight é um projeto acadêmico voltado à organização e visualização de indicadores industriais. Neste repositório, a equipe documenta o módulo EnergiaDC, que consulta e apresenta indicadores de consumo energético de um datacenter.

A solução utiliza uma aplicação web em React, uma API REST em Java com Spring Boot e persistência em banco de dados relacional. O módulo permite consultar consumo total, consumo de TI, PUE e custo estimado, além de apresentar gráficos e alertas relacionados aos dados retornados pela API.

Registrar a identificação institucional e acadêmica do trabalho, apresentar os integrantes e contextualizar o módulo desenvolvido. O conteúdo técnico, as instruções de execução e as evidências estão organizados no README e nos demais documentos deste repositório.
